# `data/`

Empty on a fresh clone — this file is the only thing tracked here.

Populated by:

- `HANZE_events.csv`, downloaded manually (Zenodo) — see `../docs/data.md`.
- `HANZE_events_parsed.csv`, the cached cause-text parse of it, written by
  the notebook itself (Part 12b) — see `../docs/data.md`.
- `<tag>.h5` population/subsample caches, generated by the notebook itself
  (Part 8, whenever `data_backend="hdf5"`) — see `../docs/data.md` and
  `../docs/reproducibility.md`.

Everything else in this folder is gitignored: large, and either
reproducible from the notebook or downloadable from source.
