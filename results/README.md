# `results/`

Empty on a fresh clone — this file is the only thing tracked here.

Populated by running the notebook's Part 10 (`save_results`) and Part 10c
(the sensitivity sweep's own CSV cache) — see `../docs/data.md` for the
file schemas and `../docs/reproducibility.md` for how each Part 10 section
triggers them.

Everything else in this folder is gitignored: large, and reproducible from
the notebook.
